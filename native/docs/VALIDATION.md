# 原生版验证记录

## 已执行的验证

0.2 版本本轮共 42 项自动化测试通过，另完成一次真实 Qt 事件循环启动、演化、退出及数据库重开恢复验证。系统命令超时与失败清理也有自动化覆盖。

- Python 单元测试：生命规则、四边环绕、滑翔机位移、256 个种子、笔刷、长代数计数、整秒调度与长暂停不补算，含单调时钟不计休眠时间的情形。
- 文件与 SQLite：编解码往返、CRC、截断与坏文件拒绝、解压大小限制、单个检查点重开恢复、覆盖备份、相同图形不归档、导入事务回滚、显式空槽身份保留。
- 网页互通：Python 编码的 .life 和 .lifebank 已由实际网页解码器读取；固定样本来自网页提交 cb2f0d200ec9b39c1558005d2c837cad41c30331 的编码器，包括空、滑翔机、脉冲星、高斯帕枪及随机种子。后续修改网页格式时应重新验证，不能仅让 Python 自己编码再自己解码。
- Qt offscreen：真实加载 PySide6，运行原生绘制；1920×1080 与 2560×1440 两种输出均检查控制区边界、命中区不重叠、底部留白和预览背景。
- 鼠标事件：普通左键绘制、Shift＋左键擦除、右键擦除。
- 系统接口：输出解析与参数，缺少设备／工具的降级。此环境不验证真实设备的开关结果。

## 尚未实机验证

- Kubuntu 的 Plasma 版本、原生 Wayland／X11 平台插件及 100%、125%、150% 缩放。
- 实际音频服务、NetworkManager、BlueZ 和 Polkit 会话授权。
- 系统配色方案切换后其他应用的响应。
- 真正挂起／休眠／唤醒、长期连续运行与异常断电。
- 桌面背景层、桌面图标和现有面板的输入／叠放关系。0.3 增加插件代码，尚未在真实 Plasma 会话验收。

在这些项目通过前，本版本是原生应用实验版，不能称为已经完成的桌面壁纸替代品。


## 0.2 新增验证

- 蓝牙：软件禁用解除后再通电、硬件禁用不尝试解除、解除权限失败、退出码 0 但 BlueZ 输出错误、命令成功但读回不符、关闭时不解除禁用。
- Wi-Fi：中文 SSID、大小写、冒号与反斜杠转义、隐藏网络和断开状态。
- 速度：指定八挡、旧检查点挡位迁移、连续条点击边界。
- 日志：MAC 脱敏、文件权限与轮换数量上限。
- 更新器：旧版回退、拒绝未准备版本、拒绝路径穿越、模拟依赖失败保留旧版；用实际 Qt 子进程完成新版本启动绘制自检后才允许激活。
- 真实蓝牙硬件错误仍需用户设备日志定位，不能把模拟状态机测试称为用户设备已经修复。


## 0.2.1 更新器修复

- 默认更新不再查询 GitHub API，直接下载完整归档。
- 验证 ZIP 注释中的提交号，兼容分支／标签根目录，无注释时使用内容摘要标识。
- 新增默认路径无 API、指定 SHA 下载、无注释归档、分支 404 回退标签、403 不误判为图形问题及提交号不符拒绝等回归覆盖。
- 云端安装校验改为执行用户实际使用的默认 main 分支路径，不再只测试显式 SHA 参数。

## 0.3 新增验证

本轮 60 项测试通过（包括原有覆盖）；两个目标分辨率重新绘制。新增验证包括：

- 向下 LWSS 四代位移两格；完整流星雨组合的整体位移；十二个大图案边界、尺寸和确定性。
- 不补零百分比、B／K／M 整数边界；物理网卡过滤、差分速率、网卡变动、累计计数回退和大间隔采样。
- 已连接蓝牙设备去重计数，不读取配对总数；未知和命令不支持时不伪装零设备。
- 真实 Qt TCP／HTTP 事件循环：无凭据与网页 Origin 拒绝，PNG 实际解码，非法分辨率与坐标拒绝，绘制／连续拖动／Shift 擦除／释放。
- QML 核心呈现实际加载并从后台取图，转发绘制与释放事件。测试将 WallpaperItem 替换为 Item，将 Plasma Action 替换为 Qt Action；**不等于已验证 KDE 模块加载或真实桌面事件路由**。
- 插件安装保留连接凭据、凭据权限 0600；没有把用户日志或真实名称提交到仓库。
- Fcitx 控制器与 Rime ASCII／标点流程通过模拟 D-Bus 输出与方法参数验证；保留最近输入上下文语义；识别不了的标点和重复候选不会触发；信息页布局命中区无重叠。真实 Fcitx／Wayland 焦点和用户 Rime 菜单还需实测。
- 全部测试联跑曾触发 Qt 对象清理崩溃：QProcess 完成后先断开信号、再延迟删除，超时回调等待进程退出后发出；测试看门狗也在事件循环结束后停止。修复后联跑通过。

预览图使用模拟系统读数，仅展示美术状态；不是宿主 KDE 的运行截图。数月运行、真实睡眠和后台性能仍未完成长期实测。

## 0.3.1 验证

本轮 68 项自动测试通过，包括：

- QML 呈现覆盖整个宿主：100%／125%／150%／200% 比例；2560×1440 宿主在 DPR=2 且源图封顶时仍铺满。检查统一缩放、等比例呈现和右侧页切换按钮命中，而非只验证 PNG 能否解码。
- 在加载新分辨率前，鼠标按当前实际显示帧换算；不同长宽比的宿主保持画面比例。大预设缩略图也改为保持比例，并通过像素区域测量检查。
- 蓝牙 500 ms 刷新，Powered 确认后在同轮更新连接数；关闭后归零；旧请求结果不能覆盖新操作。两个目标分辨率逐一验证 0–5 台的五格设备条填充。
- 新增 008–024 横向镜像，其中 010–018／020–024 还上下镜像。008／009 竖直 9 格周期贯穿边界，列距均匀，四代整体向下位移两格。
- 基础 Schick 引擎 12 代水平位移 6 格、Weekender 7 代竖直位移 2 格；双蜂穿梭 46 周期、十五周期振荡器 15 周期，以及它们的完整阵列周期。
- 以 1920×1080 和 2560×1440 实际绘制，重新检查读数、代数层级、五格条和预览比例；预览仍使用明确标注的模拟系统读数。

QML 测试通过替换 KDE 特有根项来模拟宿主及 DPR，不等于已经复现用户设备的整个 Plasma／Wayland 会话。需要用户更新后检查真实桌面效果；若插件仍加载旧缓存，应切换壁纸类型或重新登录。
