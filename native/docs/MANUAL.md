# 原生版操作手册

本手册对应 native/ 实验版。主界面用像素块、数字和少量字母表示功能；文件窗口与错误说明使用原生 Qt 对话框。

## 启动与模式

运行 `python native/run.py` 打开普通窗口；`--fullscreen` 全屏。第一版还不是 Wayland 背景层，不能替换桌面而保留全部桌面图标。只保证 1920×1080、2560×1440 两种物理分辨率下完整布局。其他窗口尺寸以整数倍居中预览。

右上角 X 退出；最下排四角图标切换全屏。没有全局或应用字母快捷键，不需要键盘获取焦点。

## 画面与运行

- 左侧为生命场，256×180，四边环绕。
- 左键拖动绘制；右键或 Shift＋左键拖动擦除。
- 一次拖动沿途连线，不会因为快速拖动留下大段空白。拖动期间暂时冻结演化，结束后恢复原先的运行状态。
- 时钟使用电脑本地时区。日期右侧 1–7 表示星期一至星期日。
- G 为常驻代数，至少显示十位数字；不足补零。加载新图形、导入单个文件和清空时归零。修改与选择编号不归零。
- C 和 M 分别为 CPU 占用和内存使用百分比，`---` 表示尚不可用；CPU 需至少两次采样。

日期下面第一排，从左到右：

| 图案 | 功能 |
| --- | --- |
| 方格 | 运行／暂停，填满表示运行 |
| 三角竖线 | 暂停并前进一代 |
| 日／月 | 切换 KDE 标准明暗配色；成功读回系统状态后同步应用配色 |
| 四色块 | 只循环应用自身六套配色，不修改系统 |

日／月仅切换系统配色方案，不替换 Plasma 全局主题或桌面布局。若找不到标准方案、工具或服务，会显示不可用或错误。

速度条是连续的填充条，有八挡：1/8、1/4、1/2、1、2、4、8、16 代／秒，点击条上的位置选择。只在条上方显示当前挡位，条下不显示每挡数字。前四挡与时钟整秒对齐。每 8 秒一代并非每分钟都从秒数 00 重排，而是按连续系统时间计数。休眠、事件循环长时间停止后不补算。

## 预设与随机

P 是预设，骰子是随机，点击切换；各有 000–255 编号。左右箭头逐一选择，八个位格从左到右权重是 128、64、32、16、8、4、2、1，点击翻转对应位。

切换编号或模式只更新预览。点击预览框才载入游戏区，并暂停。小图形在预览中居中放大，大图形缩略显示；保存的数据始终是完整网格和原始位置。

内置 001 滑翔机、002 轻型飞船、003 脉冲星、004 高斯帕枪、005 R-pentomino、006 Acorn、007 Diehard；其余为空。随机种子与当前网页版本一致。

预览下方一排：

| 图案 | 功能 |
| --- | --- |
| 软盘 | 将当前游戏保存到当前 P 槽；随机模式不可保存 |
| 向下箭头 | 导出选中的预设／随机图形，**不是未保存的当前游戏画面** |
| 向上箭头 | 导入 `.life` 或 `.lifebank` |
| 叠放方框 | 进入被替换预设备份页 |

覆盖已有图形会留下旧版本；相同内容重复保存不新增备份。备份页用左右箭头选择旧版本，向下箭头导出所选旧版本，最右软盘导出完整预设库（含全部旧版本），左上叠框返回。没有旧版本也可以导出完整库。

单个 `.life` 导入到编辑区，需要显式保存才能覆盖预设。`.lifebank` 先完整校验，再原子合并；损坏文件不应留下部分导入。支持与当前网页版本互换文件。

## 系统控制

预设区下面是系统音量与无线控制：

- 喇叭图标：切换默认输出的静音。音量条点击选择 0–100%，不修改输入／麦克风音量。
- Wi-Fi 图标：无线开／关。不会删除连接配置。关闭后会断开无线网络。右侧显示当前已连接 Wi-Fi 的真实 SSID，保留大小写、中文、冒号和反斜杠；不是连接配置的别名。多个无线接口同时连接时显示命令返回的第一个已连接 SSID。
- 名称采用像素化字形并自动换行，悬停可查看完整名称；未连接／关闭时显示 `---`，已连接但 SSID 为空时显示“隐藏网络”。中文名称需要系统存在相应字体。
- 蓝牙图标：默认适配器电源开／关。开启前检查 rfkill；软件禁用时尝试仅解除蓝牙的软件禁用，硬件禁用无法自动解除。操作超时更宽容，并反复读回 Powered 确认；BlueZ 即使退出码为 0 但输出错误，也按失败处理。关闭会断开蓝牙设备，不删除配对，不修改 Wi-Fi 开关。
- 高亮填充表示开启，暗色表示关闭，更暗／不可用表示缺少设备、服务或工具。
- `...` 表示命令正在执行。界面以操作后读回的真实状态为准，不在发出命令时直接假装切换成功。

这些操作由当前用户的系统权限决定；无需也不应以 root 运行整个应用。当前开发环境没有真实 KDE 桌面，系统控制必须在你的 Kubuntu 上进一步实测。若某一操作失败，请保留原生错误对话框中的信息。

## 最下排

从左到右为清空、笔刷、独立笔刷尺寸读数、残影和全屏。笔刷 1、3、5 循环。清空不会删除预设；残影只影响显示，不参与演化。

## 自动保存与恢复

预设库和运行现场分开。应用会自动覆盖保存一份当前检查点：网格、代数、运行状态、速度、配色等。每 10 秒保存，结束绘制和正常退出时补存；设置变化约 200 ms 后保存。不记录逐帧历史或每次操作前后帧。

重新启动优先恢复检查点。之前在运行则恢复运行，之前暂停则保持暂停；不补算关闭和休眠期间的演化。残影是临时视觉效果，重启后不恢复残影。

数据库在 Qt 的 AppDataLocation，通常位于 `~/.local/share/ConwayWallpaper/ConwayDesktop/state.sqlite3`；可用 `--data-dir` 指定目录。不要依赖一个固定路径猜测，运行时以 Qt 实际返回位置为准。关闭应用后可备份整个数据目录。网页 IndexedDB 不会自动与原生数据库共享，请先从网页导出 `.lifebank` 再导入原生应用。

左上状态点正常为绿色，检查点保存失败为红色。突然断电、强制结束进程时可能回退最近约 10 秒；磁盘故障或写入失败时不能保证保存成功。重要预设仍建议另存 `.lifebank`。


## 日志与蓝牙排查

普通运行默认写入轮换日志，点击左上角状态点打开日志目录。目录通常为 `~/.local/share/ConwayWallpaper/ConwayDesktop/logs/`，也可用 `--log-dir` 指定。`conway.log` 为应用日志；`--debug` 增加命令参数、耗时、输出和读回记录。普通轮询不反复写入相同错误，避免日志迅速膨胀。

每个日志文件上限 1 MiB，最多保留当前文件加 3 个旧文件。默认不记录 Wi-Fi 名称或密码，蓝牙 MAC 地址脱敏。Qt 警告、未处理异常、数据库保存失败也进入日志。

蓝牙出现 `org.bluez.Error.Failed` 时，不能仅凭这个通用错误确定是权限或驱动问题。程序会记录目标状态、rfkill 硬件／软件禁用、命令返回及适配器读回。不会自动重启蓝牙服务、解除所有无线设备禁用，或要求整个程序以 root 运行。

需要进一步排查时，先按一次蓝牙按钮复现，再执行：

```bash
~/.local/bin/conway-desktop --diagnose
```

源码版则用原来的 Python 入口追加 `--diagnose`。这会做只读检查并写入独立的 `diagnostics.log`，包含内核／Qt 版本、蓝牙服务、适配器和最近蓝牙服务日志；没有读取日志的权限时会如实记录失败。该命令不需要显示窗口，也不修改无线状态。分享排查信息时可提供 `conway.log` 和 `diagnostics.log` 中相关时间段。
